\section*{Scope}
\textbf{Channel-input parameters only:} every field exposed as a BICTR entry in OAI
(\texttt{sim.h} / \texttt{bictr\_channel.h}) is listed below with the closest thesis (or
validation) quantity. A second table lists thesis or campaign quantities that are \emph{not}
separate \texttt{bictr\_*} keys in OAI but still affect (or should affect) the same experiment.

\section*{Summary reasons for mismatch classes}
\textbf{(i)} Thesis Table~5 has \emph{two} presets (fast vs aggressive): OAI exposes one row of defaults aligned to fast mode only\\
\textbf{(ii)} Earth-analog DRATS permittivity (T4/T3) seeded OAI defaults whereas lunar OAI configs deliberately replace $\varepsilon$ with regolith-centric values\\
\textbf{(iii)} Electromagnetic and signaling parameters ($f_{\mathrm{carr}}, f_{\mathrm{s}}$, waveform)
live in OAI's NR + RF simulator pipeline, mirroring thesis Python where they are scripted alongside BICTR but are not DEM geometry parameters\\
\textbf{(iv)} RFsim integration trades exact PDP + Eq.\,17 energy bookkeeping for causal IQ convolution without CP/OFDM boundary handling
